AlphaDev

核心：把「設計演算法」變成強化學習問題，讓 agent 搜尋可部署的程式。

直觀解說 →
一般 RL：學會行動 模型在每個 state 決定下一步 action。部署時仍需要 policy 在線上做決策。
VS
AlphaDev：發現程式 模型與搜尋負責產生候選 program；最後部署的是演算法本身，不是神經網路。

一般 RL Demo：訓練玩家
